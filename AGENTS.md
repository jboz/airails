# AGENTS.md

## Périmètre sources (RÈGLE ABSOLUE)

**INTERDIT** de lire, écrire, scanner, rechercher ou indexer un fichier hors de ce repository, sauf autorisation explicite et ponctuelle de l'utilisateur. Cela inclut :

- Tout chemin hors repo (`~/.*`, `/etc/`, etc.)
- Les fichiers de config système ou utilisateur hors dotfiles
- Les tentatives via `cat`, `ls`, `find`, `read`, `grep`, `glob`, ou tout autre outil

Exception : l'utilisateur demande explicitement d'aller lire/modifier un fichier externe.
